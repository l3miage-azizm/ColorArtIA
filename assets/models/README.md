# YuNet face geometry model

The ONNX model is bundled so generation never downloads a model or sends a
photo to a detection service. It locates facial landmarks to preserve existing
eye and mouth colour shapes; it does not identify people or generate artwork.

Source: https://github.com/opencv/opencv_zoo/tree/main/models/face_detection_yunet

Model: `face_detection_yunet_2023mar.onnx`
